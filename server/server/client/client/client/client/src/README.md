# BuildMind

AI Builder Platform.

BuildMind is being built from the ground up to create, analyze, build, test, repair, preview, and export real software projects.

## Current Structure

* `client/` — React + Vite frontend
* `server/` — Node.js + Express backend
* `.env.example` — environment configuration template

## Principle

BuildMind must perform real operations and produce real project files. No fake builds, fake data, or iframe-only implementations.
